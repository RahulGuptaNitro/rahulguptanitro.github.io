## Software Engineering Internship at Rapipay Fintech Pvt. Ltd. 
### (Jan'23 - Sep'23)

During my internship at Rapipay in Noida, I focused on architecting innovative fintech solutions and optimizing web performance.

**Key Contributions:**
* **Video KYC (VKYC):** Architected a product from scratch for VKYC face detection using MediaPipe and FFmpeg. This innovation resulted in a 90% reduction in VKYC operational costs. 
* **Performance Optimization:** Enhanced web application performance by 20% through strategic code refactoring and optimization while coordinating with cross-functional teams to implement interactive features. 
* **Component Library:** Developed a reusable component library and implemented responsive design for the Rapipay website using React.js.
